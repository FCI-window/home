# FCI 스토리 페이지 모바일 레이아웃 기준

RAB, ROHD, FCI, PARAN, DRE&M 등 스토리형 상세 페이지에 공통으로 적용하는 모바일 레이아웃 기준이다.

데스크톱 레이아웃은 기존 디자인을 유지하고, 모바일 미디어 쿼리에서만 아래 기준을 적용한다.

## 1. 스토리 일러스트 크기

- 모바일 기준: `max-width: 820px`
- 본문 일러스트는 중앙 정렬한다.
- 01~05번과 같은 3:2 비율의 대표 일러스트는 최대 폭을 약 `240px`로 제한한다.
- 기본 기준 크기는 약 `240px × 160px`이다.
- 화면이 240px보다 좁으면 화면 폭에 맞춰 줄인다.

~~~css
width: min(240px, calc(100% - 82px));
margin-inline: auto;
height: auto;
~~~

- 이미지를 강제로 늘리거나 줄이지 않고 `height: auto`로 원본 비율을 유지한다.
- 이미지를 클릭하면 확대되므로 모바일 화면에서는 지나치게 크게 노출하지 않는다.

## 2. 여러 이미지가 함께 있는 일러스트 영역

대표 일러스트 옆에 앱 화면이나 보조 이미지를 세로로 배치할 경우 전체 시각 영역의 최대 폭을 약 `332px`로 둔다.

~~~css
width: min(100%, 332px);
margin-inline: auto;
~~~

대표 일러스트와 오른쪽 보조 이미지 영역 사이에는 약 `10px`의 간격을 둔다. 보조 이미지 두 장을 세로로 배치할 때는 두 이미지의 합계 높이가 대표 일러스트의 높이와 비슷하도록 구성한다.

- 대표 일러스트: 약 `240px × 160px`
- 보조 이미지 영역: 약 `82px` 폭
- 보조 이미지 2장: 세로 배치
- 이미지 사이 간격: 약 `10px`
- 대표 일러스트의 원본 비율은 변경하지 않는다.

## 3. 모바일 다운로드 박스

다운로드 박스는 모바일 기준 `max-width: 640px`에서 좌우 2열로 구성한다.

~~~css
display: grid;
grid-template-columns: minmax(0, 1fr) auto;
align-items: center;
gap: 12px;
padding: 18px 16px;
border-radius: 16px;
~~~

- 왼쪽 `1fr` 영역: 제목과 설명 문구
- 오른쪽 `auto` 영역: 다운로드 버튼 2개
- 다운로드 버튼은 세로로 배치하고 오른쪽 정렬한다.
- 버튼 이미지 높이는 약 `30px`로 한다.
- 문구는 가능한 한 한 줄로 유지한다.
- 문구가 화면 폭을 넘으면 글자 크기를 자동으로 줄인다.
- 자동 축소 시에도 최소 글자 크기는 약 `11px` 이하로 내리지 않는다.

모바일 다운로드 박스 예시:

~~~text
┌──────────────────────────┬──────────┐
│ 스토리 제목               │ App Store│
│ 짧은 설명 문구             │ Google   │
│                           │ Play     │
└──────────────────────────┴──────────┘
~~~

## 4. 적용 대상과 점검 항목

이 기준은 다음 스토리 페이지에 동일하게 적용한다.

- RAB
- ROHD
- FCI
- PARAN
- DRE&M

페이지별로 문구 길이와 이미지 비율이 다를 수 있으므로 최종 확인 시 다음을 점검한다.

- 01~05번 일러스트가 모바일에서 과도하게 크지 않은지
- 이미지가 원본 비율을 유지하는지
- 보조 이미지 합계 높이가 대표 일러스트와 균형을 이루는지
- 다운로드 박스가 화면을 가로로 넘치지 않는지
- 제목과 설명 문구가 의도하지 않게 여러 줄로 깨지지 않는지
- 다운로드 버튼이 오른쪽 세로 정렬되는지
- 데스크톱 레이아웃이 변경되지 않았는지
