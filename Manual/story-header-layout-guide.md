# 스토리 페이지 상단 헤더 구성 기준

DRE&M에 적용한 상단 헤더 수정 방식을 다른 스토리 페이지에도 공통으로 적용하기 위한 기준이다.

현재 기준은 한국어 페이지에 우선 적용하며, 영어 페이지는 번역·줄바꿈 검토 시 별도로 적용한다.

## 1. 기본 구성

기존의 상단 영역에 있던 FCI 문구 포함 로고와 `FCI 홈` 버튼은 제거한다.

대신 앱 로고와 페이지 제목이 있는 `brand-row`의 오른쪽 끝에 작은 FCI 로고를 배치한다.

구성은 다음과 같다.

```text
┌────────┬──────────────────────────────┬──────┐
│ 앱 로고 │ 페이지 제목 및 설명           │ FCI  │
│        │                              │ 로고 │
└────────┴──────────────────────────────┴──────┘
```

- FCI 로고는 클릭 가능한 홈 버튼이다.
- 한국어 페이지에서는 `../ko/index.html`로 이동한다.
- 웹 화면에서는 문구가 포함된 `FCILOGOwithText.png`를 사용한다.
- 모바일에서는 문구 없는 심볼 로고를 사용한다.
- 모바일 FCI 심볼 로고의 기준 폭은 약 `34px`이다.
- 페이지 제목은 모바일에서 한 줄을 유지하고, 가용 폭에 맞춰 글자 크기를 자동으로 줄인다.

## 2. 반응형 이미지 처리

문구 포함 로고와 심볼 로고를 `<picture>`로 연결한다.

```html
<a class="brand-fci-home" href="../ko/index.html" aria-label="FCI 홈으로 이동">
  <picture>
    <source media="(max-width: 640px)" srcset="../images/FCI_basic_logo.png">
    <img src="../images/FCILOGOwithText.png" alt="FCI Factory of Creative Imagination">
  </picture>
</a>
```

공통 페이지에서 사용하려면 문구 없는 심볼 로고를 각 페이지의 상대경로에 맞춰 준비한다. 현재 DRE&M에는 `dream/images/FCI_basic_logo.png`가 있으며, 여러 페이지에서 공통으로 사용할 때는 루트 `images/FCI_basic_logo.png`에 두는 방식을 권장한다.

## 3. 모바일 제목 자동 축소

모바일에서 제목이 두 줄로 바뀌지 않도록 다음 조건을 적용한다.

- 제목 요소에 `white-space: nowrap`을 적용한다.
- 제목 컨테이너에 `min-width: 0`을 적용한다.
- 제목의 실제 표시 폭이 컨테이너 폭을 넘으면 JavaScript로 글자 크기를 단계적으로 줄인다.
- 데스크톱에서는 원래의 `clamp()` 글자 크기를 유지한다.
- 제목이 지나치게 작아지지 않도록 페이지별 최소 글자 크기를 확인한다.

## 4. 페이지별 적용 가능 여부

다음 네 페이지에 동일한 방식으로 적용할 수 있다.

| 페이지 | 현재 구조 | 적용 방법 |
| --- | --- | --- |
| 성경낭독녹음 `rab/index_ko.html` | 상단 `topbar`와 `brand-row`가 있음 | 상단 `topbar` 제거 후 `brand-row` 오른쪽에 FCI 로고 추가 |
| ROHD `rohd/index_ko.html` | 상단 `topbar`와 `brand-row`가 있음 | 동일하게 적용 |
| PARAN `paran/index.html` | 상단 `topbar`와 `brand-row`가 있음 | 동일하게 적용 |
| FCI `fci/index_ko.html` | 별도 `topbar`는 없고 제목 줄에 `FCI 홈` 버튼이 있음 | 기존 텍스트 버튼을 작은 FCI 로고 버튼으로 교체하고 모바일 심볼 로고 적용 |

성경낭독녹음, ROHD, PARAN은 DRE&M과 구조가 거의 같아 공통 CSS와 JavaScript를 그대로 재사용할 수 있다. FCI는 이미 제목 줄 안에 홈 버튼이 있으므로 상단 전체를 다시 만들기보다 현재 제목 줄의 버튼만 같은 로고 방식으로 바꾸는 것이 적절하다.

## 5. 적용 전 확인 사항

- 각 페이지의 FCI 홈 상대경로가 올바른지 확인한다.
- 앱 로고와 FCI 로고가 겹치지 않는지 확인한다.
- 모바일에서 제목이 한 줄로 유지되는지 확인한다.
- 모바일 FCI 심볼 로고가 제목을 압박하지 않는지 확인한다.
- 웹 화면의 제목·앱 로고·FCI 로고 비율이 자연스러운지 확인한다.
- 영어 페이지는 언어별 제목 길이에 따라 최소 글자 크기를 다시 확인한다.
